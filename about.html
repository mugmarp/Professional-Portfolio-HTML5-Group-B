Technical Terminology

Semantic HTML
HTML tags that describe the meaning of content, such as article and nav, rather than its appearance.
Jetpack Compose M3
Android's modern declarative UI toolkit using Material Design 3 components.
Offline-first Architecture
A design approach where the app stores data locally in Room/SQLite and syncs with a server when connectivity is available.
Write-through Cache
A caching strategy where writes go to both the local cache and the remote store at the same time, keeping them consistent.
Termux:X11
A Termux add-on that allows running Linux GUI applications on Android via the X11 display protocol.
Android NDK
Native Development Kit that lets developers write performance-critical parts of Android apps in C or C++.
